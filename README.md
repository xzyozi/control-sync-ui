# control-sync-ui

ブラウザ側に状態の正本と決定論的な計算ロジックを持たせ、外部PCの画面操作（制御状態）に応じてデータ送信を動的に制御する、UI非依存のTypeScript同期基盤です。Gitサブモジュールとして親プロジェクトへ組み込める構成を目指します。

現在は v0.1 MVP の要件定義の段階で、実装コードはありません。
